ToDo List Connector

ToDo List Connector は、作者が自分のパソコンだけで使う個人用のツールです。作者本人の Google ToDo リストを読み、作者が頼んだときだけ新しいタスクを追加します。読んだタスクは、その日にやることの整理に使います。

一般向けに配布しているものではありません。作者以外の人が使うことはありません。

About (English)

ToDo List Connector is a personal tool that runs only on its author's own computer. It reads the author's own Google Tasks and, only when the author asks, adds new tasks. The tasks it reads are used to plan the author's day. It isn't distributed to or used by anyone else.

このツールについて

ToDo List Connector は、作者が自分のパソコンだけで使う個人用のツールです。作者以外の人が使うことはありません。

使う情報

作者本人の Google アカウントにある、Google ToDo リストの情報だけを使います。

  • ToDo リストの名前
  • タスクのタイトル、メモ、期限、完了したかどうか

作者が頼んだときだけ、新しいタスクを追加したり、既存のタスクを完了にしたり、期限を変えたりします。タスクを削除することはありません。

情報の扱い方

  • 読み取った情報は、作者のパソコンの中で、その日にやることの整理に使うだけです。
  • 第三者に売ったり、渡したり、公開したりしません。
  • 広告には使いません。
  • ログイン用の情報は、作者のパソコンの中にだけ保存します。

Google API から受け取った情報の使い方は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

Privacy Policy (English)

Last updated: 18 November 2026

ToDo List Connector is a personal tool used only by its author on the author's own computer.

It uses only the author's own Google Tasks data: task list names, and each task's title, notes, due date and completion status. Only when the author asks, it adds a new task, marks an existing task as completed, or changes a task's due date. It never deletes tasks.

This information is used only on the author's computer to plan the author's day. It's never sold, shared with third parties, published, or used for advertising. Sign-in credentials are stored only on the author's computer.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time from Google Account third-party connections.

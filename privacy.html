このツールについて

Kuro AIOS は、作者が自分のパソコンだけで使う個人用のツールです。作者以外の人が使うことはありません。

読み取る情報

作者本人の Google アカウントにある、次の情報だけを読み取ります。

  • Google カレンダーの予定
  • Gmail のメール
  • Google ToDo リストのタスク

情報の扱い方

  • 読み取った情報は、作者のパソコンの中で作業の整理に使うだけです。
  • 第三者に売ったり、渡したり、公開したりしません。
  • 広告には使いません。
  • ログイン用の情報は、作者のパソコンの中にだけ保存します。

Google API から受け取った情報の使い方は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

Privacy Policy (English)

Last updated: 15 November 2026

Kuro AIOS is a personal tool used only by its author on the author's own computer.

It reads only the author's own Google Calendar events, Gmail messages, and Google Tasks. This information is used only on the author's computer to organise daily work. It is never sold, shared with third parties, published, or used for advertising. Sign-in credentials are stored only on the author's computer.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time from Google Account third-party connections.
